# PIT II — Cupcakes Gourmet | Gabriel Ferreira de Oliveira

Projeto acadêmico de **Gabriel Ferreira de Oliveira — RGM 33704431**, desenvolvido como continuidade da PIT I.

## Contexto
Na PIT I foi escolhida a **Situação-Problema 1**, relacionada ao desenvolvimento de um app mobile para uma loja de cupcakes gourmet.

O foco principal foi a **User Story US05**, que representa a necessidade de o cliente visualizar os detalhes completos de cada produto antes de realizar a compra.

## Objetivo da solução
Permitir que o usuário consulte informações completas do cupcake, incluindo:
- foto;
- descrição;
- ingredientes;
- tamanho;
- preço;
- opção de adicionar ao carrinho.

## Base conceitual da PIT I
- História de Usuário;
- Critérios de Aceitação;
- Regras de Negócio;
- Requisitos Não Funcionais;
- abordagem ágil Scrum;
- validação de fluxo principal e cenários alternativos.

## PIT II
Nesta etapa, a proposta é transformar a US05 em uma solução funcional, documentada e testável, mantendo o código e as atualizações no GitHub.
